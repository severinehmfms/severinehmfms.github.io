# severinehmfms.github.io

Titre : CV fictif
Sujet : Créer une page web CV

Auteur : Séverine Hori Maitrehut

Description : 
La consigne était de créer un CV pour le web, en utilisant HTML, CSS et Javascript.
J'ai choisi de créer un fichier JSON pour les données du CV, pour une meilleure séparation données/application.
La première version a été faite avec du CSS de base, une seconde version de ce site a été modifiée pour utiliser Bootstrap.
La version actuellement en ligne est la version normale.
